# PARA 文件整理助手

Windows x64 PARA 文件整理助手的便携版本发布仓库。

从 [Releases](https://github.com/Nivy001/PARA_Legal_File_Organizer/releases) 下载 Portable Full ZIP，完整解压后运行对应版本的 PARAOrganizer 可执行文件。包内包含程序依赖，需要微软 WebView2 Runtime。

0.10.1 支持拖动二级文件夹标题行跨分类移动和排序，以及将外部文件拖入二、三级标题行复制到对应目录。

当前构建完成本机测试与包完整性校验；Windows 10/11 完整矩阵验收未签收，发布时标注为 Pre-release。
